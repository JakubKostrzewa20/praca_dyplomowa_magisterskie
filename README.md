
# Praca dyplomowa zrealizowana na WEITI 

## Przygotowanie środowiska
Przygotowanie środowiska conda:
```bash
conda env create environment_final.yml
pip install -r requirements.txt
```
Po utworzeniu środowiska należy je aktywować
```bash
conda activate tf_gpu
```
## Uruchamianie aplikacji

Aby uruchomić aplikacje Flutter należy:

Uruchomić emulator wybranego telefonu w aplikacji Android Studio.

Po uruchomieniu aplikacji przejść do folederu z aplikacją:
```bash
cd flutter\flutter_application_1
```

Uruchomić aplikację komedną:
```bash
flutter run
```
## Uruchamianie notatników

Pliki zawierające zbiór danych nie zostały dołączone do repozytorium ze względu na ich rozmiar. Należy również dostosować ścieżki do danych wejściowych w plikach odpowiedzialnych za przygotowanie zbioru i w plikach odpowiedzilanych za szkolenie.
